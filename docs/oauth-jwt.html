Кто может тратить деньги Алисы

Who may spend Alice’s money

Ledger API теперь за OAuth 2.0. Свой сервер авторизации выдаёт JWT, а API проверяет каждый токен и пускает пользователя только к его счетам. Тесты атакуют обе стороны: поддельные токены, кражу кода и refresh-токена, чужие счета.

The Ledger API now sits behind OAuth 2.0. Our own authorization server issues JWTs; the API checks every token and lets a user touch only their own accounts. The tests attack both sides: forged tokens, a stolen code and refresh token, other people’s accounts.

      Refresh rotation · RFC 9700 §4.14
      
Украденный refresh-токен убивает всю сессию
A stolen refresh token kills the whole session

      
Каждое обновление выдаёт новый refresh-токен, старый гаснет. Если старый приходит снова, значит его копия у кого-то ещё. Сервер не знает, у кого именно, поэтому отзывает всю цепочку.

      
Every refresh issues a new refresh token and burns the old one. If an old one comes back, someone else has a copy; the server cannot tell who, so it revokes the whole chain.

    

    

      
      
      
    

    

    

  


  

    

      JWKS · RFC 7517
      
Смена ключа подписи без простоя
Changing the signing key without downtime

      
API скачивает публичные ключи один раз и кэширует их. Отозванный ключ работает, пока кэш не устареет. Тест измеряет это с кэшем в 1 секунду.

      
The API downloads the public keys once and caches them. A retired key keeps working until the cache goes stale; the test measures it with a 1-second cache.
